# おはなし字幕

ブラウザで日本語の発言を大きな吹き出しで表示するアプリです。新しい発言を上に、古い発言を下に並べます。

## 使い方

1. [おはなし字幕を開く](https://muraoooo.github.io/ohanashi-caption/)。Chrome推奨です。開いただけではマイクは始まりません。
2. 「⚙ 設定」で認識方式を確認します。初期値は端末内認識です。日本語モデルが準備されていない場合は、本人の操作で準備します。
3. 「認識を開始」を押し、ブラウザのマイク許可を確認します。「認識を停止」で止めます。
4. 発言履歴は使っているブラウザのこのサイト用領域に保存されます。「履歴を消す」は確認画面で確定した場合だけ実行されます。

Chromeのクラウド認識を選ぶと、音声がChrome/Googleの認識サービスへ送られます。方式選択と送信先の確認チェックなしに開始せず、端末内方式から自動で切り替わることもありません。音声ファイルはこのアプリに保存しません。
